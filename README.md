# Simple Sales Analysis

My first data analysis project using Python.

## Tools

* Python
* Pandas
* Matplotlib
* Google Colab

## Questions

This project analyzes a small sales dataset to find:

* Total revenue
* Revenue by product
* Revenue by month
* Highest-selling products

## What I learned

* Creating a Pandas DataFrame
* Creating new columns
* Using `groupby()`
* Calculating revenue
* Creating basic charts with Matplotlib

## Project

The analysis is available in `Sales_Analysis.ipynb`.
